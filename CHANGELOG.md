# Changelog

## Unreleased

## 0.2.2 — 2026-07-20

- Fixed a brief dashboard flicker and duplicate heating sound when returning to Swiftea while a mug was already connected.

## 0.2.1 — 2026-07-19

- Fixed an update preference migration that could let an older Swiftea installation install a new version without first showing the update prompt.
- Fixed the post-update “What’s New” window so each release note is displayed as a separate bullet.

## 0.2.0 — 2026-07-19

- Swiftea can now reconnect eligible saved mugs after connection loss, Mac wake, app activation, or Bluetooth recovery, while continuing to respect mugs you deliberately disconnected.
- Empty-mug handling now preserves your remembered target, helping the mug resume its normal refill behavior even when Swiftea is closed.
- Swiftea’s menu bar companion now keeps mug status, heating, and target-temperature controls close at hand, whether you prefer the Dock, the menu bar, or both.
- A new visual welcome guide explains setup, key features, and safe use before Swiftea connects to a mug.
- Discovery now includes clear, step-by-step pairing guidance.
- Added a 12-hour / 24-hour time preference, clearer chart labels, and more refined temperature controls throughout the app.
- Improved reliability and security around Bluetooth discovery, local mug history, diagnostics, and software updates.

## 0.1.0

- Initial public release.
