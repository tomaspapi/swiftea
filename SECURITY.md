# Security

Swiftea is a local-first macOS app. It talks to Ember mugs directly over Bluetooth and does not use a backend, account system, analytics service, or cloud relay for mug control.

Please do not open a public issue for security vulnerabilities. Use GitHub's private vulnerability reporting for this repository if it is available, or contact the maintainer privately through GitHub.

When reporting an issue, avoid sharing information you consider private, such as full device serial numbers, exported logs, or local file paths.

Release builds are signed and notarized outside GitHub. Signing and update credentials are not stored in this repository.
